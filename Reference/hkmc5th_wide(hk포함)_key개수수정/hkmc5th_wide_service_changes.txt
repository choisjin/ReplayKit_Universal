3. send_key_by_name() 변경 내용
--------------------------------------------------------------------------------

[변경 전]
  is_msg / is_dial 두 가지 플래그만 처리.
  *_PRE_K 별도 처리 없음.

[변경 후]
  is_long 플래그 추가:
    - 키 정의에 "long": True 가 있고 호출자가 sub_cmd=SHORT_KEY인 경우
      자동으로 LONG_KEY(0x44)로 전환하여 송신.
    - 호출자가 명시적으로 LONG_KEY를 전달한 경우에도 동일하게 동작.

  처리 우선순위:
    1. msg  → send_key_message(cmd, sub_cmd)
    2. dial → send_key(cmd, DIAL_ACTION, key_data, direction)
    3. long + SHORT_KEY 호출 → send_key(cmd, LONG_KEY, key_data)
    4. SHORT_KEY → send_key(cmd, SHORT_KEY, key_data)   [단일 패킷]
    5. LONG_KEY  → send_key(cmd, LONG_KEY, key_data)    [단일 패킷]
    6. 기타 sub_cmd → 호출자 지정 그대로 송신

4. Key 값 비교 — 라이브러리(MKBD_*) vs 기존 Wide Service(HKEY_*)
--------------------------------------------------------------------------------

  두 네이밍 체계의 hex 값은 완전히 동일.
  차이는 이름뿐 (MKBD_*: 미디어 키보드 보드 관점 / HKEY_*: 범용 하드키 관점).

  라이브러리(MKBD)      값     Wide Service(HKEY)    값   일치
  ─────────────────────────────────────────────────────────────
  MKBD_MAP            0x11   HKEY_FMAM             0x11  ✅
  MKBD_RADIO          0x12   HKEY_MEDIA            0x12  ✅ (이름 불일치)
  MKBD_NAV            0x13   HKEY_SEEK             0x13  ✅ (이름 불일치)
  MKBD_MEDIA          0x14   HKEY_TRACK            0x14  ✅ (이름 불일치)
  MKBD_CUSTOM         0x16   HKEY_NAV              0x16  ✅ (이름 불일치)
  MKBD_SETUP          0x18   HKEY_SETUP            0x18  ✅
  MKBD_POWER_VOLUME_PRESS   0xF0  HKEY_VOLUME_CENTER  0xF0  ✅
  MKBD_POWER_VOLUME_CLOCK   0xF1  HKEY_VOLUME_DIAL    0xF1  ✅
  MKBD_TUNE_PRESS     0x1C   HKEY_TUNE_CENTER      0x1C  ✅
  MKBD_TUNE_CLOCK     0xA0   HKEY_TUNE_DIAL        0xA0  ✅

  ※ 모든 값 일치. 라이브러리 기준 MKBD_* 이름으로 통일함.
